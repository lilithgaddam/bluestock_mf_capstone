# Bluestock Mutual Fund Analytics Capstone

## Project Overview

This project analyzes the Indian mutual fund industry using historical NAV, AUM, SIP, transaction, portfolio holdings and performance datasets.

The objective is to build a complete analytics pipeline covering:

* Data ingestion
* Data cleaning
* Database design
* Exploratory data analysis
* Performance analytics
* Advanced risk analytics
* Interactive dashboarding

## Tech Stack

* Python
* Pandas
* NumPy
* SQLite
* SQLAlchemy
* Jupyter Notebook
